### 02 / Areas of interest

| Discipline | What I look for |
| :-- | :-- |

| **Dynamic analysis** | Runtime behavior, memory inspection, breakpoints, and call tracing. |
| **Binary internals** | PE format, x86/x64 assembly, calling conventions, and Windows APIs. |
